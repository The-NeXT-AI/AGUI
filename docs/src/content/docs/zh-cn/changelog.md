## 当前发布方向

AGUI Desktop 当前基于 ASP v1：内置 Codex、Claude Code、OpenCode、Pi、Grok、Kimi、Kilo 的 provider adapter，扩展 engine 版本为 `0.2.0`。

## 最近更新

- 文档已支持英文与简体中文。
- Provider、扩展开发、产品定制和多 Agent 会话指南已归入侧边栏结构。
- 搜索、主题选择、语言切换和顶部导航已按 Mintlify Docs 风格调整。
