## AGUI 解决什么问题

AGUI 为编码 Agent 桌面端提供稳定的宿主界面：

- Provider adapter 将各家 Agent 输出转换为 ASP 事件。
- Shell 以一致的方式渲染对话、计划、工具调用、diff、artifact、resource、审批和追问。
- 会话保留各 provider 自己的连续上下文，不会把一个 provider 的会话 ID 泄露给另一个 provider。
- 扩展可以新增界面 surface 和 Agent 能力，不需要 patch 核心 renderer 代码。

## 认识仓库结构

```text
packages/app          Renderer React UI、Shell、聊天、扩展 runtime
packages/asp          ASP protocol、transport、provider store、adapter
packages/runtime      Electron 与 Node runtime 共享服务
packages/server       纯 Web 模式 JSON-RPC server
packages/extensions   Extension manifest、IPC 与 UI schema 类型
packages/electron     Electron shell、IPC、preload、桌面集成
docs                  Astro 文档站与既有 Markdown 文档
```
