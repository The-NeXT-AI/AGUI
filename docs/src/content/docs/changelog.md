## Current release track

AGUI Desktop currently targets ASP v1: built-in provider adapters for Codex, Claude Code, OpenCode, Pi, Grok, Kimi, and Kilo, running on the `0.2.0` extension engine.

## Recent updates

- Bilingual documentation is available in English and Simplified Chinese.
- Provider, extension, customization, and multi-agent guides are organized under the documentation sidebar.
- Search, theme selection, language switching, and navigation are styled to match the Mintlify documentation experience.
