## Why AGUI

AGUI gives coding agent desktop apps a stable host surface:

- Provider adapters translate each agent into ASP events.
- The shell renders conversations, plans, tool calls, diffs, artifacts, resources, approvals, and follow-up questions consistently.
- Sessions keep provider-specific continuity without leaking one provider's session ID into another provider.
- Extensions add new surfaces and agent capabilities without patching core renderer code.

## Find your way around the repo

```text
packages/app          Renderer React UI, shell, chat, extension runtime
packages/asp          ASP protocol, transports, provider store, adapters
packages/runtime      Shared Electron and Node runtime services
packages/server       Pure web mode JSON-RPC server
packages/extensions   Extension manifest, IPC, and UI schema types
packages/electron     Electron shell, IPC, preload, desktop integrations
docs                  Astro documentation site and legacy Markdown docs
```
