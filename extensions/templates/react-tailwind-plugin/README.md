# React Tailwind AGUI Extension Template

This template mirrors the production GitHub extension shape:

- TypeScript backend compiled to `dist/extension.js`
- React + Tailwind UI surfaces compiled into self-contained HTML files
- Session tree, composer control, configuration view, chat renderer, and detail panel examples
- Optional MCP stdio server compiled to `dist/mcp-server.js` when generated with `--with-mcp`

Create a new extension from the repository root:

```bash
node scripts/create-extension-from-template.mjs my-extension \
  --publisher agui \
  --display-name "My Extension"
```

MCP is not generated by default. Add it only when the agent needs tool access:

```bash
node scripts/create-extension-from-template.mjs my-extension --with-mcp
```

Then build and package it:

```bash
pnpm --dir extensions/my-extension build
node scripts/package-extension.mjs extensions/my-extension
```

The generated manifest points only at `dist` assets. Source files live under `src/`, and the build
script keeps plugin HTML compatible with the sandbox CSP by inlining JavaScript and CSS.
